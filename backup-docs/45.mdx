---
title: 45 - POST - Create Account
---

Use this endpoint to open an account under the integrator's domain.

## Request Example

```json
curl --request POST \
  --url https://api.ext.dbs.moneyp.dev.br/api/v2/Conta \ // Endpoint to create an account
  --header 'Authorization: <api-key>' \                  // API key for authentication
  --header 'Content-Type: application/json' \            // Specifies that the request body is in JSON format
  --header 'IdempotencyKey: <idempotencykey>' \          // Ensures the request is processed only once
  --header 'IgnoraHandshake: <ignorahandshake>' \        // Optional header to bypass handshake validation
  --data '{
  "numeroBanco": "<string>",                             // Bank number
  "numeroAgencia": "<string>",                           // Branch number
  "numeroConta": "<string>",                             // Account number
  "digitoConta": "<string>",                             // Account check digit
  "descricao": "<string>",                               // Description of the account
  "tipoGeracaoNumeroConta": 0,                           // Type of account number generation
  "modCobrTaxa": 0,                                      // Fee charging mode
  "tipoConta": 123,                                      // Account type
  "dadosCorrentista": {
    "documentoFederal": "<string>",                      // Federal document (CPF or CNPJ)
    "nome": "<string>",                                  // Full name
    "tipoPessoa": 123,                                   // Person type (individual or company)
    "situacao": 1                                        // Status (e.g., active)
  },
  "dadosContato": {
    "email": "<string>",                                 // Email address
    "telefoneFixo1": "<string>",                         // Landline phone 1
    "telefoneFixo2": "<string>",                         // Landline phone 2
    "telefoneCelular1": "<string>",                      // Mobile phone 1
    "telefoneCelular2": "<string>",                      // Mobile phone 2
    "telefoneFax": "<string>",                           // Fax number
    "paginaWeb": "<string>"                              // Website
  },
  "dadosEndereco": {
    "cep": "<string>",                                   // Postal code
    "logradouro": "<string>",                            // Street name
    "nroLogradouro": "<string>",                         // Street number
    "bairro": "<string>",                                // Neighborhood
    "complemento": "<string>",                           // Address complement
    "cidade": "<string>",                                // City
    "uf": "<string>",                                    // State (UF)
    "tipoEndereco": 1,                                   // Address type
    "tipoResidencia": 1,                                 // Residence type
    "enderecoDesde": "2023-11-07T05:31:56Z",             // Residence start date
    "enderecoPrincipal": true,                           // Is main address
    "enderecoCorrespondencia": true,                     // Is correspondence address
    "verificadoInLoco": true                             // Verified on site
  },
  "dadosPF": {
    "apelido": "<string>",                               // Nickname
    "rg": "<string>",                                    // RG (ID number)
    "rgOrgao": "<string>",                               // Issuing authority
    "rguf": "<string>",                                  // State of RG
    "rgData": "2023-11-07T05:31:56Z",                    // RG issue date
    "dtNasc": "2023-11-07T05:31:56Z",                    // Date of birth
    "sexo": "<string>",                                  // Gender
    "nacionalidade": "<string>",                         // Nationality
    "naturalDeCidade": "<string>",                       // City of birth
    "naturalDeUF": "<string>",                           // State of birth
    "estadoCivil": 1,                                    // Marital status
    "escolaridade": 1,                                   // Education level
    "nomePai": "<string>",                               // Father's name
    "nomeMae": "<string>",                               // Mother's name
    "nomeConjuge": "<string>",                           // Spouse's name
    "dtNascConjuge": "2023-11-07T05:31:56Z",             // Spouse's date of birth
    "cpfConjuge": "<string>",                            // Spouse's CPF
    "rgConjuge": "<string>",                             // Spouse's RG
    "rgOrgaoConjuge": "<string>",                        // Spouse's RG issuing authority
    "rgufConjuge": "<string>",                           // Spouse's RG state
    "rgDataConjuge": "2023-11-07T05:31:56Z",             // Spouse's RG issue date
    "nomeArquivoIdentificacao": "<string>",              // File name of ID document
    "arquivoIdentificacao": "<string>",                  // Base64 or file reference

    "profissao": "<string>"                              // Profession
  },
  "dadosPJ": {
    "nomeFantasia": "<string>",                          // Trade name
    "documentoEstadual": "<string>",                     // State registration
    "documentoMunicipal": "<string>",                    // Municipal registration

    "nomeResponsavelEmpresa": "<string>",                // Responsible person's name
    "cpfResponsavelEmpresa": "<string>",                 // Responsible person's CPF
    "rgResponsavelEmpresa": "<string>",                  // Responsible person's RG
    "nomeArquivoContratoSocial": "<string>",             // File name of articles of incorporation
    "arquivoContratoSocial": "<string>",                 // Base64 or file reference

```

| Field                       | Type        | Description                            |
|-----------------------------|-------------|----------------------------------------|
| "numeroBanco"               | string      | REQUIRED - Bank number - Max 3 characters |
| "numeroAgencia"             | string      | Branch number - Max 3 characters - Default 0001 |
| "numeroConta"               | string      | Account number - The 'account number' (numeroConta) is required when 'type of generation' (tipoGeracaoNumeroConta) = 0 (manual), must not be provided when tipoGeracaoNumeroConta = 1 (sequential), and can have a maximum of 12 characters |
| "digitoConta"               | string      | Account check digit - The checker digit of the bank account number can be a maximum of 1 character |
| "descricao"                 | string      | Additional information about the account             |
| "tipoGeracaoNumeroConta"    | number      | REQUIRED - Type of account number generation - Can be 0 for manual and 1 for sequential |
| "modCobrTaxa"               | number      | REQUIRED - Fee charging mode - 0-Deactivated; 1-Partner; 1-Customer                     |
| "tipoConta"                 | number      | REQUIRED - Account type - 1-CACC; 2-SVGS; 3-TRAN; 4-SLRY.                           |
| "documentoFederal"          | string      | REQUIRED - Federal document (CPF or CNPJ) - Only the numbers - Max 14 characters         |
| "nome"                      | string      | REQUIRED - Full name - Max 100 characters                              |
| "tipoPessoa"                | number      | Person type (individual or company) 1 for PF and 2 for PJ    |
| "situacao"                  | number      | Status (e.g., active) - 1 for Enabled and 2 for Deactivated                 |
| "email"                     | string      | REQUIRED - Email address - Max 60 characters                         |
| "telefoneFixo1"             | string      | Landline phone 1 - Only the numbers - Max 20 characters                       |
| "telefoneFixo2"             | string      | Landline phone 2 - Only the numbers - Max 20 characters                       |
| "telefoneCelular1"          | string      | REQUIRED - Mobile phone 1 - Only the numbers - Max 20 characters                         |

| "nomeConjuge"               | string      | Spouse's name - Max 60 characters       |
| "dtNascConjuge"             | string/date | Spouse's date of birth                  |

## Motor de Crédito

### Evento de Resposta do Motor de Crédito

Para mais informações sobre o endpoint de consulta do **Motor de Crédito**, acesse as referências de API [19 - Enviar Proposta PF](https://bmpdocs.moneyp.com.br/bureau/referencias-de-api/motor-de-credito/19-enviar-proposta-pf) e [20 - Enviar Proposta PJ](https://bmpdocs.moneyp.com.br/bureau/referencias-de-api/motor-de-credito/20-enviar-proposta-pj).

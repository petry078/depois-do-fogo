---
title: "17 - Consultar Dados no DataBusca"
openapi: post /Bureau/ConsultarDataBusca
---

Este endpoint permite a realização de consultas detalhadas a partir do documento do cliente, seja pessoa física ou jurídica. 

A resposta é retornada em formato JSON e contém dados estruturados, incluindo endereço, e-mail, telefone, endereço comercial, situação fiscal e informações sobre parcerias. 

Esses dados são extraídos de fontes confiáveis e podem ser utilizados para análise e tomada de decisões com base em informações cadastrais e fiscais do cliente.

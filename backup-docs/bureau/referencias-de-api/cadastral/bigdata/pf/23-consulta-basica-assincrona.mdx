---
title: "23 - Consulta Básica Assíncrona"
openapi: post /Bureau/DadosBasicosReceitaFederalPFAsync
---

Este endpoint permite consultar de forma básica, os dados cadastrais de uma pessoa física no formato de resposta assíncrona. A resposta é retornada em ‘String JSON’ serializado e inclui as seguintes informações: nome, idade, nome da mãe, número do documento, informação da Receita e indicação de óbito.

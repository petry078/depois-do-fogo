title: "26 - KYC Síncrona"
openapi: post /Bureau/KycSancoesPF
---

Este endpoint permite consultas básicas sobre uma pessoa física, no formato de resposta rápida (Síncrono). A resposta é uma 'String JSON' serializada que inclui as seguintes informações:

* PEP: indicação se a pessoa é PEP ou não;
* Sanções: histórico de sanções aplicadas;
* Contribuições eleitorais: histórico de contribuição eleitoral.

---
title: "33 - Dados Históricos Assíncrona"
openapi: post /Bureau/HistoricoCadastralPJAsync
---

Este endpoint realiza consultas assíncronas e retorna, em formato de ‘String JSON’ serializada, os dados históricos de um documento jurídico. 

A resposta contém as seguintes informações principais: 

* Idade da empresa; 
* Lista de CNAEs; 
* Lista de nomes; 
* Lista de regimes fiscais.

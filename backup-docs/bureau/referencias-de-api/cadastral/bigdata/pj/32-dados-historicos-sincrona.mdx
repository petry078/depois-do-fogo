---
title: "32 - Dados Históricos Síncrona"
openapi: post /Bureau/HistoricoCadastralPJ
---

Este endpoint realiza consultas síncronas e retorna, em formato de ‘String JSON’ serializada, os dados históricos de um documento jurídico. 

A resposta contém as seguintes informações principais: 

* Idade da empresa; 
* Lista de CNAEs; 
* Lista de nomes; 
* Lista de regimes fiscais.

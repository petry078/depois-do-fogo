---
title: "30 - Dados Cadastrais Síncrona"
openapi: post /Bureau/DadosBasicosReceitaFederalPJ
---

Este endpoint permite consultas de forma básica, os dados cadastrais de um documento Jurídica, no formato de resposta rápida (Síncrono). A resposta é retornada em ‘String JSON’ serializado e inclui as seguintes informações: Nome, data fundação, CNAE, Email, telefones, Endereço.

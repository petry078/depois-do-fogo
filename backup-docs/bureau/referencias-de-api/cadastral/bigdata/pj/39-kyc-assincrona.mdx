title: "39 - KYC Assíncrona"
openapi: post /Bureau/KycSancoesPJAsync
---

Este endpoint realiza consultas assíncronas e retorna, em formato 'String JSON' serializada, os dados de mídia negativa relacionados a um documento jurídico. 

A resposta inclui: 

* Informação se é PEP;
* Históricos de sanções;
* Histório por período de sanções entre 07 a 360 dias.

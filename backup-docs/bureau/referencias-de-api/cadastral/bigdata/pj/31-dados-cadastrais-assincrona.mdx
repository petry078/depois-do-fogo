---
title: "31 - Dados Cadastrais Assíncrona"
openapi: post /Bureau/DadosBasicosReceitaFederalPJAsync
---

Este endpoint permite consultas de forma básica, os dados cadastrais de um documento Jurídica, no formato de resposta assíncrona. A resposta é retornada em 'String JSON' serializado e inclui as seguintes informações: 

* Nome;
* Data fundação;
* CNAE;
* Email;
* Telefones;
* Endereço.

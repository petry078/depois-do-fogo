title: "40 - Consultar Proposta"

Utilize este endpoint para consultar uma proposta enviada ao motor de crédito. As informações recebidas nesta consulta serão as mesmas que você receberá no call-back, após a análise do motor.

Para prosseguir com a consulta, é necessário preencher os campos obrigatórios: `codigoPropostaCliente` e `codigoInstituicao`.

<Tip>Para requisições no ambiente de homologação, utilize o ID de proposta `T240624001` no campo `codigoPropostaCliente`.</Tip>

O tipo de retorno dependerá das informações da política, sendo um retorno modular.

O exemplo de retorno mostrado no lado direito desta tela está resumido.

Na linha `"json":`, o retorno vem serializado, sendo necessário deserializar para uma melhor visualização.

Aqui estão os exemplos de retorno deserializado que aparece no campo `"json":`.

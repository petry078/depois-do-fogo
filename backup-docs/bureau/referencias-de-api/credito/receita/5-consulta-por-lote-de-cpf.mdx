---
title: 5 - Consulta por Lote de CPFs
openapi: post /Bureau/ConsultarReceitaLoteCPF

Utilize este endpoint para realizar consultas em lote que verificam a situação fiscal de cidadãos em um relatório centralizado.

<Expandable title="Exemplo de retorno completo">

O exemplo de retorno, mostrado no lado direito desta tela, está resumido. O retorno do Bureau é enviado de forma serializada, sendo necessário deserializá-lo para uma melhor visualização. O campo `TipoCallback` deve ser enviado com o valor `2` em todas as chamadas.

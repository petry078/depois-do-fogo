---
title: 12 - Consulta Basic Grafeno por CNPJ
openapi: post /Bureau/GrafenoConsultarReceitaCNPJBasic
---

Utilize este endpoint para consultar os dados básicos de uma empresa, obtendo informações como:

* Situação Cadastral atualizada;
* Endereço;
* Atividade Econômica;
* Natureza Jurídica;
* Telefone.

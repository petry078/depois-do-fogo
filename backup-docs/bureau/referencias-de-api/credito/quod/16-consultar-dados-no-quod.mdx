title: 16 - Consultar Dados no QUOD
openapi: post /Bureau/ConsultaFraudeQuodRufra
---

Por meio deste endpoint, você terá acesso à base Rufra, que reúne informações unificadas sobre marcações de fraudes e golpes. Para realizar sua consulta, é obrigatório enviar o documento do cliente. Além disso, você pode incluir informações opcionais, como Chave Pix, e-mail e celular, para obter resultados mais completos. A QUOD utiliza inteligência em sua base e analisa dados de interoperabilidade de outras instituições, garantindo sempre um retorno atualizado e completo.

<Note>Os exemplos abaixo mostram como pode ser o retorno de uma consulta feita pela QUOD. Porém, no ambiente de testes (homologação), a QUOD não repassa todas as informações completas nas consultas — isso ocorre apenas em produção.</Note>

Os dados apresentados abaixo correspondem aos retornos de produção.

This page provides an overview of the staging and production environments for our APIs. Here you will find the specific URLs for each environment that allow you to securely and appropriately access the functionality of our APIs, whether for testing during development or for full-scale operations after launch. Each URL is categorized by its specific purpose, making it easier to integrate and use our APIs correctly.

## Homologation Environment

Abaixo estão as URLs base para acesso às diferentes APIs no ambiente de homologação, que devem ser utilizadas durante o desenvolvimento e testes:

* **APIs de homologação (conectado o serviço):**

```bash
https://api.bmpdigital.moneyp.dev.br/
```

## Production Environment

When applications are ready to be released to the public, the following URLs should be used to access the APIs in the production environment:

* **Production APIs (connected to the service):**

```bash
https://api.bmpdigital.moneyp.com.br/
```

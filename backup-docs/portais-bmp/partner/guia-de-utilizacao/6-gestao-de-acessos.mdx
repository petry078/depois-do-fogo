**Gestão de Acessos**, é a sexta opção do menu vertical a esquerda. Nessa seção é possível visualizar, criar, editar e excluir usuários do portal **Partner**. Também é possível definir o nível de acesso de cada usuário.

Para adicionar um novo usuário do Partner, siga os passos abaixo:

1. Clique no botão `Novo`, indicado pelo ícone de **+**;
2. No campo `Email *` informe o email do usuário. Esse email é o usuário no momento da autenticação.
3. No campo `Nome *`, informe o nome o usuário.
4. No dropdown `Perfis`, selecione os perfis de privilégio que esse usuário terá no portal Partner.
5. Clique no botão `SALVAR`.

Para mais informações sobre os perfis de privilégios, acesse o documento [Primeiro Acesso](https://bmpmoneyplus-sandbox.mintlify.app/portais-bmp/partner/primeiro-acesso).

**Propostas** é a segunda opção do menu vertical a esquerda. Nessa seção é possível consultar propostas cadastradas, realizar cancelamentos e, quando habilitado, atualizar dados bancários vinculados à operação.

Essa gestão é feita pelas páginas:

* Propostas;
* Atualizar Dados Bancários;
* Cancelar Proposta.

## Propostas

Na página de **Propostas**, é possível visualizar uma lista de propostas organizadas por:

* Número da proposta;
* Data;
* Cliente;
* Documento;
* Valor;
* Parcelas;
* Aprovado;
* Valor Empresa;
* Situação;
* Risco?;
* Analista;
* Tipo de contrato.

Para cada proposta, é possível acessar mais informações. Para isso, identifique a proposta que deseja ver mais informações e clique no botão **DETALHES**. Ao clicar no botão, o usuário é redirecionado para a página da proposta, com todos os dados disponíveis sobre ela.

Também é possível atualiar, exportar para Execel e filtrar a lista de propostas. Para isso, utilize os botões **Filtro**, **Recarregar** e **Exportar para Excel**.

O filtro pode ser aplicado por um **intervalo de tempo**, **situação da proposta**, **tipos de contrato** e **número da proposta**.

## Atualizar Dados Bancários

A página **Atualizar Dados Bancários**, permite atualizar os dados de conta bancáris dos beneficiários atuais das propostas realizadas.

Para isso, identifique o beneficiário que precisa ter seus dados bancários atualizados na lista, e clique no botão **ATUALIZAR**, localizado na última coluna da tabela de beneficiários.

Para atualizar os dados bancários, é necessário informar os seguintes dados:

* Banco;
* Tipo de Conta;
* Agência;
* Dígito da agência;
* Número da conta;
* Dígito da conta;
* Documento Federal Pagamento;
* Nome Pagamento.

## Gerar Comprovante de Pagamento

Na página **Comprovantes de pagamento**, informe um **intervalo de tempo** ou o **número da proposta** para acessar as informações de uma proposta paga:

* Beneficiário;
* Dados bancários;
* Data do pagamento;
* Valor pago;
* PDF do recibo completo do pagamento.

## Cancelar Proposta

Na página de **Cancelar Proposta**, informe o **número da proposta** e o **motivo de cancelamento** para cancelar uma proposta.

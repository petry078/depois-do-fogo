**Gestão de Contratos** é a quarta opção do menu vertical a esquerda. Nessa seção é possível acessar os contratos ativos e averbados, boletos gerados e registros de callbacks relacionados à agenda contratual.

Essa gestão é feita pelas páginas:

* Visualizar Contratos;
* Boletos;
* Callback Agenda.

## Visualizar Contratos

Na página de **Visualizar Contratos**, é possível filtrar os contratos por **CPF/CNPJ**, **Nome/Razão Social**, **Número da Proposta** e **intervalo de data**. Para isso, clique no botão **Filtro**, indicado pelo ícone de funíl.

Também é possível exportar os dados filtrados em uma planilha no formato Excel. Para isso, clique no botão **Exportar para Excel**, indicado pelo ícone de **documento com um X no meio**. 

## Boletos

Na página de **Boletos**, é possível filtrar os contratos por **Número da Proposta**, **Número do Boleto** e **intervalo de data**. Para isso, clique no botão **Filtro**, indicado pelo ícone de funíl.

Também é possível exportar os dados filtrados em uma planilha no formato Excel. Para isso, clique no botão **Exportar para Excel**, indicado pelo ícone de **documento com um X no meio**. 

## Callback Agenda

Na página de **Callback Agenda**, é possível filtrar os contratos por **Número da Proposta**, **Código de Integração** e **intervalo de data**. Para isso, clique no botão **Filtro**, indicado pelo ícone de funíl.

Também é possível exportar os dados filtrados em uma planilha no formato Excel. Para isso, clique no botão **Exportar para Excel**, indicado pelo ícone de **documento com um X no meio**.

Esta página fornece uma visão geral dos ambientes de homologação e produção para nossas APIs. Aqui, você encontrará as URLs específicas para cada ambiente que permitem o acesso seguro e adequado às funcionalidades das nossas APIs, seja para testes durante a fase de desenvolvimento ou para operações em escala real após o lançamento. Cada URL está categorizada por sua finalidade específica, facilitando a integração e o uso correto das APIs.

## Ambiente de Homologação

Abaixo estão as URLs base para acesso às diferentes APIs no ambiente de homologação, que devem ser utilizadas durante o desenvolvimento e testes:


Quando os aplicativos estão prontos para serem lançados ao público, as seguintes URLs devem ser utilizadas para acessar as APIs no ambiente de produção:

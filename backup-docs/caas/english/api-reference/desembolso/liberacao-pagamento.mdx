Through this endpoint, our partner can release the proposal to the payment queue after receiving the “finalized” proposal status. In this case, the disbursement process will be our responsibility.

| Proposta | PropostaLiberar     | Liberar  | C0065  | V0002         | The proposal has already been released                                                                       |
| Proposta | PropostaLiberar     | Liberar  | C0065  | V0003         | The proposal cannot be released because its status is `{SituacaoPropostaEnum.GetDescricao(proposta.Situacao)}`|

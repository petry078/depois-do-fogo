---
title: "8 - Save Addresses"
openapi: post /Pessoa/SalvarEnderecos
version: 'English'
---

Through this endpoint, the partner includes or updates address records of a specific client.
To update, it is necessary to send the "código" field, filled with the record code in the BMP database, or the search will be done through the "CEP" field.

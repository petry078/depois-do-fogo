This endpoint is intended for querying the payment confirmation:


```
https://reports.moneyp.dev.br/imprimir?impressao=S&tipo=recibo&codigoProposta={{GUID_DA_PROPOSTA}}
```

Replace `{{GUID_DA_PROPOSTA}}` with the proposal code when making the request.

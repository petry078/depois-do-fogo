---
title: "20 - Incluir Avalista"
openapi: post /Proposta/IncluirAvalista
---

Por meio deste endpoint o parceiro faz inclusão dos dados de um avalista para uma proposta.
O avalista pode ser pessoa física ou jurídica, e os campos não são obrigatórios, basta realizar o preenchimento do DTO conforme a necessidade.

  <Expandable title="Tabela EstadoCivil">
  | ID  | Descrição                    |
  | --- | ---------------------------- |
  | 1   | Solteiro                     |
  | 2   | Casado                       |
  | 3   | Desquitado                   |
  | 4   | Divorciado                   |
  | 5   | Separado                     |
  | 6   | Viúvo                        |
  | 7   | Outros                       |
  | 8   | Não informado                |
  | 9   | Vínculo Conjugal             |
  </Expandable>

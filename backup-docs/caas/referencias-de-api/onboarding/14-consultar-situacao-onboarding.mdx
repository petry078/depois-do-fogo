Por meio deste endpoint o parceiro realiza a consulta do status em que se encontra o processo de onboarding.

## Mensagens de erro

A tabela abaixo representa as mensagens de erro que podem ser retornadas ao tentar realizar uma requisição.

<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

<Note>No exemplo de retorno ao lado, o campo `code` representa a coluna **Código** desta tabela; o campo `context` representa a coluna **Código Detalhado**; e o campo `message` representa a coluna **Mensagem**.</Note>

| Categoria | Operação                | Ação                       | Código | Código Detalhado | Mensagem                                                                                             |
|-----------|-------------------------|----------------------------|--------|------------------|------------------------------------------------------------------------------------------------------|
| Pessoa    | ConsultaSituacaoOnBoarding | ConsultarSituacaoOnBoarding | C0043  | V0001            | Documento Inválido                                                                                  |
| Pessoa    | ConsultaSituacaoOnBoarding | ConsultarSituacaoOnBoarding | C0108  | V0001            | Documento Federal deve ser informado                                                                  |
| Pessoa    | ConsultaSituacaoOnBoarding | ConsultarSituacaoOnBoarding | C0108  | V0002            | Cliente não encontrado com o documento {documentoCliente}                                            |
| Pessoa    | ConsultaSituacaoOnBoarding | ConsultarSituacaoOnBoarding | C0108  | V0003            | Cliente não cadastrado pelo parceiro de integração                                                    |
</Expandable>

---

Por meio deste endpoint o parceiro inclui os dados de veículo para uma proposta.
O veículo obrigatoriamente deve ter uma placa informada, demais campos são opcionais. 
Os dados de veículos são validados pelos nossos analistas de crédito e servem como base para aprovar ou rejeitar a proposta. O uso será de acordo com a necessidade da integração.

**Regras e Validações:**

* A mesma placa não pode ser incluída mais de uma vez na proposta;
* Campos alfanuméricos serão truncados conforme o tamanho definido no manual;
* O campo `documentoFederalProprietario` aceita strings com 11 caracteres para CPF e 14 caracteres para CNPJ (apenas números).

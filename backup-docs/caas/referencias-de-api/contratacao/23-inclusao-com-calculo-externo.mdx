openapi: post /Proposta/IncluirCalculoExterno
---

Por meio deste endpoint, o parceiro pode utilizar o próprio calculo para incluir as propostas. 

<Warning>O percentual do IOF é fixo e deve ser sempre 3%, tanto para pessoa física como para jurídica, conforme o regulamento do Banco Central do Brasil.</Warning>

<Tip>Neste endpoint, ambos os parâmetros `CodigoBanco` e  `NumeroBanco` podem ser utilizados. O campo `CodigoBanco` refere-se ao Identificador do Sistema de Pagamentos Brasileiro (ISPB) e espera um valor em números, enquanto o campo `NumeroBanco` refere-se ao código bancário, que possui 3 dígitos numéricos e espera o valor como string. Exemplo: `"CodigoBanco": 90400888, "NumeroBanco": "033"`.</Tip>

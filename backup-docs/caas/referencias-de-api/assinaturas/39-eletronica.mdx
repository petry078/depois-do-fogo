Por meio deste endpoint o parceiro será direcionado ao nosso ambiente para realizar a assinatura da proposta.

- Nesse contexto é permitida a inclusão de assinantes da proposta.
- O procedimento padrão determina que a proposta só pode ser finalizada se todos os assinantes cadastrados tenham realizado a assinatura da proposta. Sendo assim, de acordo com os proeminentes, o sistema auxiliar irá controlar as assinaturas de cada indivíduo. 
- Os assinantes que receberem a notificação por e-mail terão acesso a proposta para assinar a mesma e também terão possibilidade de gerenciar as assinaturas pendentes, desde que parametrizados para isto, podendo notificar os assinantes.
- O método exige os parâmetros de autenticação e de localização da proposta, assim como uma lista de assinantes.

Para mais informações sobre a implementação e requisitos deste endpoint, acesse o documento [Guia Completo dos Métodos de Assinatura de Cédulas de Crédito Bancário](https://bmpmoneyplus-sandbox.mintlify.app/caas/assinaturas#como-utilizar%3F-2).

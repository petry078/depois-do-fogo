---
title: "9 - Gerar Único Boleto"
openapi: post /AgendaRecebivel/GerarUnicoBoleto
---

Permite gerar um único boleto para as parcelas informadas definindo data de vencimento e valor de desconto, podendo ou não notificar o cliente.

## Mensagens de erro

A tabela abaixo representa as mensagens de erro que podem ser retornadas ao tentar realizar uma requisição.

<Expandable title="Mensagens de requisições com erro">

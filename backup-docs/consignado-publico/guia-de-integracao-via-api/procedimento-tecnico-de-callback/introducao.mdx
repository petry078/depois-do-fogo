**Callback**, ou **webhook**, é um mecanismo que envia informações após o acontecimento de um evento específico.

No contexto das APIs da **BMP**, um callback é enviado automaticamente, sempre que eventos específicos ocorrem no sistema.

Esse mecanismo é utilizado para notificar atualizações das situações das propostas, eliminando a necessidade de verificações constantes.

Nesse contexto, as informações são recebidas de maneira automatizada e em tempo real, sem a necessidade do parceiro executar um comando para se atualizar de uma resposta.

Nesta seção de **Procedimento Técnico de Callback**, apresentamos como esse procedimento funciona, sua importância nas integrações e como utilizá-lo no desenvolvimento da sua aplicação ao utilizar as APIs da BMP.

<Warning>Nossos callbacks não devem ser mapeados de forma restrita. Campos adicionais podem ser incluídos nos payloads dos callbacks retornados.</Warning>

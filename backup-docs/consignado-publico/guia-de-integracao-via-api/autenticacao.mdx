A autenticação dos parceiros **Consignado Público INSS** é feita pela BMP.

É necessário que o parceiro se preocupe apenas com suas credenciais de acesso, enviadas por e-mail, após o credenciamento da BMP.

## Processo de autenticação

<Steps>

<Step title="Credenciamento BMP">

Realizamos o credenciamento do parceiro nos sistemas internos e são geradas as credenciais de acesso (usuário, senha e identificador do parceiro).

</Step>

<Step title="Entrega das Credenciais">

Encaminhamos as credenciais geradas no passo anterior via e-mail.

Essas credenciais são essenciais para utilizar as APIs do **Consignado Público INSS**.

</Step>

<Step title="Endpoint de autenticação">

Com as credenciais enviadas por e-mail em mãos, realize uma requisição para o endpoint de autenticação.

Essa requisição retorna um token de uso da API.

</Step>

<Step title="Utilização da API">

Utilize o token gerado no endpoint de autenticação nas requisições do fluxo de contratação do produto.

</Step> 

</Steps>

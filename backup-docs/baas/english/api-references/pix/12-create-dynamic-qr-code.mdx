Unlike a static QR Code, which has no expiration date, a dynamic QR Code for immediate payment has a shelf life.

Therefore, the QR Code may expire in the following scenarios:

* Immediately after payment (one-time payment QR Code);
* On the date and time set at the time of issuance.

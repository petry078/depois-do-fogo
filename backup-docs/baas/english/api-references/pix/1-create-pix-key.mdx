---
title: "1 - Create Pix Key"
openapi: post /api/v2/Chave
---

Through this endpoint, the partner can register a new Pix key, expanding their payment options. Key options include: CPF/CNPJ, email, cell phone number, or a random key.

<Warning>To use this endpoint, you must perform double verification through MFA to create a key that uses "email" or "phone"</Warning>

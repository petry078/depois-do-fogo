---
title: "38 - Importar Arquivo CNAB 240"
openapi: post /api/CNAB/240/Importar
---

Por meio deste endpoint, o parceiro pode executar a importação do arquivo CNAB 240, que é de uso exclusivo de transações do tipo TED, transações internas, pagamentos de boletos e transações via PIX.

<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

| Endpoint               | Mensagem de erro                                        |
|------------------------|---------------------------------------------------------|
| /api/CNAB/240/Importar | Arquivo inválido: O arquivo não possui a estrutura mínima. |
| /api/CNAB/240/Importar | A linha {linha + 1} deve ter 240 caracteres. |
| /api/CNAB/240/Importar | Nome do arquivo inválido: Sequência de Remessa do nome do arquivo deve ser igual a presente na primeira linha do arquivo. |
| /api/CNAB/240/Importar | Arquivo inválido: O arquivo não possui a estrutura mínima. |

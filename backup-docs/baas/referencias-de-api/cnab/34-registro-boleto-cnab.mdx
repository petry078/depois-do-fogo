---
title: "34 - Registro Boleto CNAB"
openapi: post /api/Arquivo/EnviarArquivo
---

Por meio deste endpoint, o parceiro pode enviar um arquivo do tipo CNAB 400  para efetuar registros de boletos em lote.

<Warning>Antes de efetuar o registro do boleto é necessário que o emissor tenha um número de cedente vinculado a conta e uma carteira registrada, sendo carteira “1” para boleto simples e “9” para CNAB que é a situação que se aplica neste endpoint. O registro do cedente deve ser realizado no endpoint /api/Cedente e o vínculo do cedente a uma carteira deve ser realizado no endpoint `/api/Cedente/AdicionarCarteira`.</Warning>

<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

| Endpoint                   | Mensagem de erro                                        |
|----------------------------|---------------------------------------------------------|
| /api/Arquivo/EnviarArquivo | Extensão de arquivo inválida. Arquivo deve ser do tipo '.zip' ou '.REM' |
| /api/Arquivo/EnviarArquivo | Tipo de arquivo não implementado |
| /api/Arquivo/EnviarArquivo | Conta {Situacao} |
| /api/Arquivo/EnviarArquivo | Operador sem parceiro cadastrado |
| /api/Arquivo/EnviarArquivo | Parceiro não autorizado para esta conta. {Numero} |
| /api/Arquivo/EnviarArquivo | O modelo conta deve ser informado |
| /api/Arquivo/EnviarArquivo | A conta não pode ser do modelo 'Conta {modeloConta} |
| /api/Arquivo/EnviarArquivo | Número do Cedente ou da Carteira Inválido |
| /api/Arquivo/EnviarArquivo | Não é possível importar o arquivo. Verifique a situação do cedente |
| /api/Arquivo/EnviarArquivo | Não existe cedente ativo para a conta informada |
| /api/Arquivo/EnviarArquivo | Número do Cedente informado não corresponde ao cedente relacionado a conta informada |
| /api/Arquivo/EnviarArquivo | Número da Carteira não encontrada |
| /api/Arquivo/EnviarArquivo | Relação Cedente x Carteira não encontrada |
| /api/Arquivo/EnviarArquivo | Cedente x Carteira não permite importação de arquivos CNAB |
| /api/Arquivo/EnviarArquivo | Conteúdo arquivo em branco ou inválido |
| /api/Arquivo/EnviarArquivo | Layout do arquivo CNAB inconsistente |

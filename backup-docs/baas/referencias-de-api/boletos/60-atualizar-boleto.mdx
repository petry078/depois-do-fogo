---
title: "60 - Atualizar Boleto"
openapi: post /api/Boleto/Alterar
---

Por meio deste endpoint, o parceiro pode permitir que o operador realize atualizações em um determinado boleto desde que esteja dentro do vencimento e não tenha sido pago.

<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

| Endpoint            | Mensagem de erro                             | 
|---------------------|----------------------------------------------|
| /api/Boleto/Alterar | Parâmetro inválido |
| /api/Boleto/Alterar | O código de barras não pode exceder 44 caracteres |
| /api/Boleto/Alterar | Registro não encontrado |
| /api/Boleto/Alterar | Não é possível excluir ou alterar um boleto cedido |
| /api/Boleto/Alterar | Código de juros 'Percentual Dias Corridos' não permitido para o tipo de modelo de cálculo 01 |
| /api/Boleto/Alterar | A nova data de vencimento não pode ser menor que a data atual |

</Expandable>

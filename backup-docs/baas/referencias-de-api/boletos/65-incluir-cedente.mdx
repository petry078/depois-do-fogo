---
title: "65 - Incluir Cedente"
openapi: post /api/Cedente
---

Por meio deste endpoint, o parceiro pode realizar o cadastro de um número de **Cedente**, pois esse processo é necessário dar início ao processo de registro de boletos. 

Para utilizar este endpoint é necessário ter uma conta ativa junto a BMP-274 a criação de conta pode ser realizada no endpoint /api/v2/Conta, após a criação de conta e de cedente é necessário vinculá-lo a uma carteira no endpoint /api/Cedente/AdicionarCarteira.

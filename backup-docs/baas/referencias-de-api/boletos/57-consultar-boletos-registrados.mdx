---
title: "57 - Consultar Boletos Registrados"
openapi: get /api/Boleto/BoletosRegistrados
---

Por meio desse endpoint, o parceiro pode listar os boletos registrados junto a BMP-274, esse processo é exclusivo ao integrador.

<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

| Endpoint                       | Mensagem de erro                                                                   |
|--------------------------------|------------------------------------------------------------------------------------|
| /api/Boleto/BoletosRegistrados | Necessário informar pelo menos um dos intervalos de datas (Registro ou Vencimento) |
| /api/Boleto/BoletosRegistrados | Data Registro Inicial não pode ser maior que Data Registro Final                   |
| /api/Boleto/BoletosRegistrados | Intervalo entre Datas de Registro não pode ser superior a 31 dias                  |
| /api/Boleto/BoletosRegistrados | Data Vencimento Inicial não pode ser maior que Data Vencimento Final               |
| /api/Boleto/BoletosRegistrados | Intervalo entre Datas de Vencimento não pode ser superior a 31 dias                |

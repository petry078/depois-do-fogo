---
title: "58 - Cancelar Registro"
openapi: post /api/Boleto/CancelarRegistro
---

Por meio desse endpoint, o parceiro pode cancelar o registro de um boleto desde que ainda não tenha sido pago.

<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

| Endpoint                     | Mensagem de erro                             | 
|------------------------------|----------------------------------------------|
| /api/Boleto/CancelarRegistro | Parâmetro inválido |
| /api/Boleto/CancelarRegistro | Somente um parâmetro deve ser informado |
| /api/Boleto/CancelarRegistro | Boleto não localizado para cancelamento |
| /api/Boleto/CancelarRegistro | Conta {Situacao} 
| /api/Boleto/CancelarRegistro | Operador não encontrado |
| /api/Boleto/CancelarRegistro | Parceiro não autorizado para esta conta {Numero} |
| /api/Boleto/CancelarRegistro | Não é possível excluir ou alterar um boleto cedido |

</Expandable>

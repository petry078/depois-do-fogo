---
title: 56 - Consultar Registro de Boleto
openapi: get /api/Boleto/ConsultarRegistro
---

Por meio desse endpoint, o parceiro pode consultar o registro de um determinado boleto junto ao órgão responsável.

<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

| Endpoint                      | Mensagem de erro         |
|-------------------------------|--------------------------|
| /api/Boleto/ConsultarRegistro | Parâmetro inválido       |
| /api/Boleto/ConsultarRegistro	| Somente um parâmetro deve ser informado |
| /api/Boleto/ConsultarRegistro	| O código de barras não pode exceder 44 caracteres |
| /api/Boleto/ConsultarRegistro	| Registro não encontrado |
| /api/Boleto/ConsultarRegistro	| Registro não encontrado |

</Expandable>

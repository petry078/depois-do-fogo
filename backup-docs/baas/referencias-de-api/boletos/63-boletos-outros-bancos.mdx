---
title: "63 - Boletos Outros Bancos"
openapi: get /api/BoletoOutrosBancos
---

Por meio deste endpoint, o parceiro pode realizar uma consulta de boletos que possuem registro em outra instituição financeira.

<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

| Endpoint                | Mensagem de erro         |
|-------------------------|--------------------------|
| /api/BoletoOutrosBancos | Operador não informado |
| /api/BoletoOutrosBancos | Operador sem parceiro configurado |
| /api/BoletoOutrosBancos | O limite de consulta de boletos por hora foi atingido. Tente novamente mais tarde |

</Expandable>

---
title: "55 - Registrar Boleto"
openapi: post /api/Boleto/Registrar
---

Por meio deste endpoint, o parceiro pode efetuar o registro de um boleto.

O processo da API por parte do integrador, faz com que o boleto seja registrado junto ao órgão responsável.

Antes de efetuar o registro do boleto é necessário que o emissor tenha um número de cedente vinculado a conta e uma carteira registrada, sendo carteira “1” para boleto simples que é a situação que se aplica neste endpoint e “9” para CNAB.

O registro do cedente deve ser realizado no endpoint /api/Cedente e o vínculo do cedente a uma carteira deve ser realizado no endpoint /api/Cedente/AdicionarCarteira.

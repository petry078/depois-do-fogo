---
title: "69 - Solicitar Protesto"
openapi: post /api/ProtestoBoleto/Solicitar
---

Por meio desde endpoint, é possível realizar o protesto de boletos sendo possível o envio de até 500 boletos, até 3 dias úteis para entrar em vigência.

<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

| Endpoint                      | Mensagem de erro                                        |
|-------------------------------|---------------------------------------------------------|
| /api/ProtestoBoleto/Solicitar | Não foram informados códigos de barras válidos para protesto de boleto |
| /api/ProtestoBoleto/Solicitar | As contas pagamento: {string.Join(", ", contasInvalidas)}, não possuem tarifário configurado para protesto |
| /api/ProtestoBoleto/Solicitar | A conta pagamento: {string.Join(", ", contasInvalidas)}, não possui tarifário configurado para protesto |

</Expandable>

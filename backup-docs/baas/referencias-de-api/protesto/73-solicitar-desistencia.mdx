---
title: "73 - Solicitar Desistência"
openapi: post /api/ProtestoBoleto/SolicitarDesistencia
---

Por meio deste endpoint, é possível solicitar a desistência do comando de protesto. 

Uma requisição de "Desistência" só poderá ser acatada antes que o comando do protesto seja formalizado. 

<Info>A opção de "Desistência" só está disponível para os boletos com o status "Em protesto".</Info>


<Expandable title="Mensagens de requisições com erro">

O retorno de uma requisição com status HTTP 400 (Bad Request) pode incluir as seguintes mensagens de erro:

| Endpoint                      | Mensagem de erro                                        |
|-------------------------------|---------------------------------------------------------|
| /api/ProtestoBoleto/SolicitarDesistencia | Não foram informados códigos de barras válidos para desistência de protesto |
| /api/ProtestoBoleto/SolicitarDesistencia | Não há boletos em protestos para desistência |
| /api/ProtestoBoleto/SolicitarDesistencia | Data limite não pode ser menor que a data de vencimento {nameof(alteracaoBoleto.DtLimPgtoTit)} |
| /api/ProtestoBoleto/SolicitarDesistencia | Data do vencimento não pode ser menor que a data atual |
| /api/ProtestoBoleto/SolicitarDesistencia | Valor do boleto não pode ser menor igual a zero |

</Expandable>

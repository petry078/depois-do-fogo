---
title: "20 - Solicitar MFA para Reivindicação" 
openapi: post /api/Reivindicacao/SolicitarMFA
---  

Por meio deste endpoint, o parceiro pode enviar uma solicitação de autenticação de múltiplos fatores (MFA), quando executar uma reivindicação de chave.
Este processo é muito importante pois desta forma o parceiro pode comprovar a titularidade da chave.

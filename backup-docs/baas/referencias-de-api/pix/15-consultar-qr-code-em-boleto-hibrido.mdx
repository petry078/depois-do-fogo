---
title: "15 - Consultar Qr Code em Boleto Híbrido"
openapi: get /api/QRCode/ConsultarByCodigoBoleto/{codigoBoleto}
---

Por meio deste endpoint, o parceiro pode consultar um Qr code que já foi disponibilizado em determinado boleto, nesse caso trata-se de um boleto que permite pagamento híbrido, ou seja, tanto pelo código barras quanto Qr Code.

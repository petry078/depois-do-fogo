---
title: "19 - Consultar Devolução de Recurso"
openapi: get /api/Recurso/Devolver/Status/{codigoTransacao}
---

Por meio deste endpoint, o parceiro pode verificar o status da devolução. O sistema trará o status da devolução.

***Requisito***  
Para consulta do status da devolução, é primordial informar o código da transação.

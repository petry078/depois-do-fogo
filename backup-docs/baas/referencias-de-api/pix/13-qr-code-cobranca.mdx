title: "13 - QR Code - Cobrança"
openapi: post /api/v2/QRCode/Cobranca

Por meio deste endpointo, o parceiro pode gerar um Qr code único para uma determinada chamada, que em seguida será descartado conforme a data de validade cadastrada, pode ou não, haver cobrança de juros e multa de acordo com a parametrização.

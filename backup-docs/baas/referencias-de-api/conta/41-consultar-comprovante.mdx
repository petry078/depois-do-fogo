---
title: "41 - Consultar Comprovante"
openapi: get /api/Comprovante/Consultar
---

Por meio deste endpoint, o parceiro pode consultar todos os tipos de comprovantes:  título de pagamento, boleto, transferência, débito, lançamentos, entre outros. 

<Warning>
Vale ressaltar que o a interface do comprovante deve ser desenvolvida no front do parceiro.
</Warning>

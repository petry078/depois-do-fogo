---
title: "48 - Pedido de Encerramento de Conta"
openapi: post /api/Conta/Encerramento
---

Por meio deste endpoint, o parceiro pode solicitar o encerramento de conta no banco 274. 

Os encerramentos de conta antes de serem executados efetivamente no sistema, passam por uma análise dos operadores do Banco, que dará sequência a demanda de encerramento.

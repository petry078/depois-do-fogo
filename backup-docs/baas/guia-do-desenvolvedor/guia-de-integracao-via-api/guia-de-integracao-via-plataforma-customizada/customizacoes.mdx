Oferecemos uma gama de opções de personalização para que a experiência no seu aplicativo espelhe a identidade visual da sua empresa. As personalizações disponíveis incluem:

### Logo da Empresa

- **Formato de Envio**: O logo deve ser enviado no formato **.svg** vetorizado para assegurar alta qualidade de visualização nos aplicativos. Esta prática garante que a apresentação do logo seja realizada com excelência, proporcionando uma experiência superior aos usuários. Seu logo será aplicado nos aplicativos e Internet Banking em uma posição fixa.

![](https://raw.githubusercontent.com/docs-petry/imagens/refs/heads/main/bmp-docs/baas/guia-de-integracao-via-plataforma-customizada/customizacoes/1.png)

### Cores

- **Cores Primárias e Secundárias:** É possível personalizar as cores primárias e secundárias que são vitais para a aplicação de componentes visuais do produto. Utilize as cores oficiais da sua empresa para manter uma consistência visual sendo possível aplicar somente uma cor primária e uma secundária.
- **​Formato de Envio:** As cores devem ser fornecidas em código hexadecimal, como por exemplo, #FFFFFF para branco.

![](https://raw.githubusercontent.com/docs-petry/imagens/refs/heads/main/bmp-docs/baas/guia-de-integracao-via-plataforma-customizada/customizacoes/2.png)

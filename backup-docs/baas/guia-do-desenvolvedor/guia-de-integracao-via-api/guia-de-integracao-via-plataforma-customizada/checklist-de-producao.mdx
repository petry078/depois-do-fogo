### Próximos passos:

#### Assinatura e Termos

- Entre em contato com nosso time comercial para realizar a assinatura do contrato e do termo de retaguarda, que inclui informações sobre o IP Fixo Público, os operadores do sistema de retaguarda e a planilha com os limites transacionais.

#### Infraestrutura

- **IP Fixo Dedicado:** O IP deve ser dedicado à rede utilizada pelos operadores para acessar a retaguarda. Sem este IP cadastrado, não será possível liberar o acesso à plataforma de retaguarda.

### Integração

- **KickOff Inicial:** Agenda de KickOff entre o parceiro e a equipe de implantação para alinhar objetivos e expectativas.

- **Criação do Grupo de WhatsApp:** Criaremos um grupo para centralizar o suporte e o atendimento.

- **Acesso aos materiais de apoio:** Disponibilizaremos os formulários para preenchimento do checklist e customizações de layout das plataformas.

**Requisitos Necessários:**

- Duns Number
- Site institucional com política de privacidade devidamente publicada
- Criação de contas organizacionais nas lojas APPLE e GOOGLE
- Pagamento de taxas das lojas
- Imagens, logo e cores [Clique aqui para mais informações.](https://bmpdocs.moneyp.com.br/baas/white-label/customizacoes)
- Documentos assinados e validados
- Credenciamento retaguarda
- Preenchimento dos formulários

#### Desenvolvimento e Publicação dos Aplicativos

Após envio dos formulários preenchidos, validaremos as informações enviadas e daremos início ao desenvolvimento do ambiente. Após finalizado os aplicativos são submetidos para análise das lojas. O prazo para análise das lojas pode variar de 7 a 10 dias úteis.

<Warning>**ATENÇÃO!** Caso haja recusa das lojas ou pendências o prazo será renovado</Warning>

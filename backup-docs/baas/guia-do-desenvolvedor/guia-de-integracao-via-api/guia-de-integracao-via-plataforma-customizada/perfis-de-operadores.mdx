## Tipos de Perfis para Operadores

Os perfis de operadores no Internet Banking e nos aplicativos móveis da BMP são projetados para oferecer diferentes níveis de acesso e controle, dependendo das responsabilidades e necessidades do usuário. Cada perfil é cuidadosamente configurado para maximizar a eficiência e a segurança das operações bancárias.

### Perfil – Correntista

O perfil **Correntista** é o mais completo, concedendo ao operador autorização total sobre todos os serviços disponíveis no Internet Banking e nos aplicativos, similar ao correntista principal. Este perfil é ideal para operadores de confiança que precisam de acesso irrestrito para gerenciar todas as funcionalidades bancárias.

- **Funcionalidades:**
  - Autorização plena para movimentações, incluindo TED, PIX, e transferências entre contas internas.
  - Registro manual ou via arquivo CNAB para boletos.
  - Pagamento de boletos.
  - Acesso a saldo, comprovantes e extratos.
  - Autorização para aprovar ou recusar movimentações.

### Perfil – Movimentação

O perfil **Movimentação** oferece acesso a quase todos os serviços disponíveis para o perfil Correntista, exceto a capacidade de aprovar movimentações financeiras e incluir novos operadores. Este perfil depende da autorização do Correntista para efetivar movimentações, proporcionando um nível intermediário de acesso.

- **Funcionalidades:**
  - Autorização prévia necessária para movimentações, como TED, PIX, e transferências entre contas internas.
  - Registro manual ou via arquivo CNAB para boletos.
  - Pagamento de boletos.
  - Acesso a saldo, comprovantes e extratos.

### Perfil – Consulta

O perfil **Consulta** é projetado para usuários que precisam monitorar a conta, mas sem a capacidade de realizar movimentações financeiras. Este perfil é adequado para funções de supervisão e auditoria.

- **Funcionalidades:**
  - Registro manual ou via arquivo CNAB para boletos.
  - Acesso a saldo, comprovantes e extratos.
  - Sem permissão para realizar TED, PIX ou transferências internas.

## Conclusão

A escolha do perfil adequado depende das necessidades específicas de acesso e controle dentro de sua organização. Ao entender claramente as capacidades de cada perfil, os administradores podem atribuir responsabilidades de maneira eficaz, garantindo que cada operador tenha as ferramentas necessárias para desempenhar suas funções sem comprometer a segurança ou a eficiência operacional.

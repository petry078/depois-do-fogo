title: "10 - Payment Receipt"
openapi: get /api/
---

This endpoint is intended for checking the payment receipt:

```
https://reports.moneyp.dev.br/imprimir?impressao=S&tipo=recibo&codigoProposta={{PROPOSAL_GUID}}
```

Replace `{{PROPOSAL_GUID}}` with the proposal GUID to perform the query request (GET).

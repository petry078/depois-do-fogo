This page provides an overview of the staging and production environments for our APIs.

Here, you will find the specific URLs for each environment that allow secure and appropriate access to the functionalities of our APIs, whether for testing during the development phase or for full-scale operations after launch.

Each URL is categorized by its specific purpose, facilitating the integration and correct use of the APIs.

## Staging Environment

Below are the base URLs for accessing the different APIs in the staging environment, which should be used during development and testing:

```
https://api.bmpdigital.moneyp.dev.br/
```

## Production Environment

When the applications are ready to be released to the public, the following URLs should be used to access the APIs in the production environment:


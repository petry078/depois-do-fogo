---
title: "6 - Cancelar Proposta"
openapi: post /FGTS/CancelarProposta
---

<Warning>***Não é possível realizar a chamada do endpoint de cancelamento com 7 dias do desembolso da proposta ou se ela se encontrar com o status de cedida (ID = 10).***</Warning>

Por meio desta endpoint o parceiro cancela uma operação de FGTS.
Regras:
- A operação não pode ultrapassar o prazo de 7 dias do momento do desembolso
- Caso ocorra desembolso da operação, será necessária a devolução do valor para nós.

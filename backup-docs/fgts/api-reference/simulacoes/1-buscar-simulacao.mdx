title: "1 - Buscar Simulação"
openapi: post /FGTS/BuscarSimulacao
---

Por meio deste endpoint o parceiro executa a simulação e busca de dados referente aos valores de FGTS disponíveis para trabalhador. 
Após o retorno dos valores, pode realizar empréstimos com garantia do Saque Aniversário, onde posteriormente serão inclusos em uma proposta. 
Esta ação antecede a inclusão e efetivação da proposta no sistema.
Regras:
- Caso seja informado o campo “Saldo”, não utilizamos o saldo verdadeiro do cliente na Caixa Econômica Federal e o cálculo será com base nos valores da nossa calculadora.
- Caso o mês de aniversário esteja incorreto, o sistema retorna um erro no momento da simulação. 
- Em caso de preenchimento do campo CPF, a consulta é realizada na Caixa Econômica Federal

<Warning>

Quando o valor do campo `ConsultaCache` for `false`, a requisição consultará o saldo do FGTS atualizado diretamente na **Caixa Econômica Federal (CEF)**; quando for `true`, o saldo será obtido do cache da BMP. Este campo não é obrigatório, caso não seja informado, o sistema assume o valor `true` como padrão.

</Warning>

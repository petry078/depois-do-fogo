---
title: "9 - Impressão de CCB"
openapi: get /api/
---

Este endpoint é usado para solicitar a consulta da impressão de um Certificado de Crédito Bancário (CCB), utilizando os parâmetros de código da proposta e código de integração:

```
https://reports.moneyp.dev.br/ImprimirCCB?Code={{CODIGO_PROPOSTA}}&Integracao={{CODIGO_INTEGRACAO}}
```

Certifique-se de substituir `{{CODIGO_PROPOSTA}}` e `{{CODIGO_INTEGRACAO}}` pelos valores apropriados ao realizar a solicitação de consulta (GET).
